# 🛒 Addis Market

Addis Market is an interactive shopping list web application built with HTML, CSS, and JavaScript.

## Features

- Add shopping items with name, price, quantity, and category
- Automatic item categorization
- Mark items as bought
- Delete individual items
- Clear the entire shopping list
- Live ETB total and item counters
- Search shopping items
- Recommended products
- Dark mode
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
