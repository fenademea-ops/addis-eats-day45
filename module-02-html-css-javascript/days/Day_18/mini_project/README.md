# TeleBirr Transaction Report

## Project Description

This project is a small TeleBirr Transaction Report system for a shop in Addis Ababa.

The program stores TeleBirr transactions and generates a report showing:

- Credit transactions
- Debit transactions
- Total credit amount
- Total debit amount
- Customer receipts
- An example of updating a transaction without changing the original object

All transaction amounts are displayed in Ethiopian Birr (ETB).
