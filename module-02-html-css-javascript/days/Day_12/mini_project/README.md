# Habesha Eatery Mini-Site

A simple, accessible 2-page website for a restaurant in Bole, Addis Ababa. Built using semantic HTML.

## Pages Included
* `index.html` — Reservations form, dish menu, and location map.
* `contact.html` — Contact form and opening hours schedule.

## How to Open the Project
1. Open this folder in **VS Code**.
2. Double-click `index.html` to open it in your web browser.
3. Use the navigation menu at the top to switch between pages.

## Accessibility Features
* **Keyboard Navigation:** Every link, input, and button can be reached using the `Tab` key and pressed with `Enter`.
* **Form Labels:** Every input has a clear `<label>` for screen readers.
* **Tables:** Tables include `<caption>` summaries and `<th scope="col">` headers.
* **Media:** Images have descriptive `alt` text, and the map iframe has a `title`.
* **W3C Valid:** Tested with 0 HTML validation errors.
