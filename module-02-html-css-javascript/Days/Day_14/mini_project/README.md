# Ethio telecom Web Portal

A responsive clone of the Ethio telecom website featuring fixed/sticky navigation, interactive mega menus, card hover effects, and embedded YouTube video streaming.

## 🚀 Key Features
- **Sticky Navigation**: Left fixed sidebar and sticky top header (`position: sticky; top: 0`).
- **Interactive UI**: Hover-activated mega menu and card elevation effects.
- **Embedded Media**: 16:9 responsive YouTube video player embeds.
- **Responsive Layout**: Designed using CSS Grid and Flexbox for all screen sizes.

## 📁 File Structure
- `index.html`: Main HTML template.
- `style.css`: Layout styles, micro-interactions, and responsive rules.
- `assets/`: Image resources.

## 💻 Tech Stack
- **HTML5** & **CSS**


## ⚡ Quick Start
Open `index.html` directly in any web browser or launch via VS Code Live Server.
