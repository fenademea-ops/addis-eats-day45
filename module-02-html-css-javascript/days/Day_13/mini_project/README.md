# Feneti Specialty Coffee — Business Profile Card

A responsive profile card built for **Feneti Specialty Coffee**, a fictional cafe in Bole, Addis Ababa.

## Features & CSS Techniques
* **Custom Properties (`:root`):** Palette colors, HSL values, and spacing defined as CSS variables and applied with `var()`.
* **Global Box Sizing:** `box-sizing: border-box` set globally across all elements.
* **Typography:** `Inter` Google Font applied to the body with generous line-height for readability.
* **Box Model Layout:** Centered card using padding, border, border-radius, and auto margins.
* **HSL Lightness Hover Effect:** Contact button hover state increases lightness from `33%` to `45%`.
* **Pseudo-elements (`::before`):** Includes a gold top accent bar and a decorative dot inside the TeleBirr badge.
* **Accessibility:** Retains visible `:focus-visible` outline for keyboard navigation.
